# تشغيل سجل الطلبات ولوحة التحكم

الهدف: كل طلب يتسجّل في جوجل شيت عندك، ويوصلك إيميل وتليجرام فورًا، وتقدري تديريه من صفحة `admin.html`.

الوقت المتوقع: **١٥ دقيقة**، ومرة واحدة بس. مش محتاجة أي خبرة برمجة — كل اللي هتعمليه نسخ ولصق.

---

## الجزء الأول: إنشاء الشيت والكود (٧ دقايق)

**١.** افتحي [sheets.new](https://sheets.new) — هيتفتح جوجل شيت جديد فاضي. سمّيه من فوق: **طلبات بوكيه**.

**٢.** من القائمة فوق اختاري **Extensions ← Apps Script**. هيتفتح تاب جديد فيه محرر كود.

**٣.** امسحي أي كود موجود في الصفحة (اعملي Ctrl+A ثم Delete).

**٤.** افتحي ملف `apps-script/Code.gs` من مجلد المشروع، انسخي **محتواه كله**، والصقيه مكان الكود اللي مسحتيه.

**٥.** اضغطي أيقونة الحفظ 💾 (أو Ctrl+S).

**٦.** من القائمة المنسدلة فوق (اللي مكتوب فيها اسم دالة) اختاري **setup** واضغطي **Run** ▶.

- أول مرة هيطلب إذن: اضغطي **Review permissions** ← اختاري حسابك ← **Advanced** ← **Go to (اسم المشروع) (unsafe)** ← **Allow**.
- الكلمة "unsafe" دي طبيعية وبتظهر لأي كود شخصي مش مراجَع من جوجل — ده كودك إنتي.

**٧.** بعد ما يخلص، هتظهر لك رسالة فيها **كلمة سر لوحة التحكم**. 

> 🔑 **انسخيها واحفظيها في مكان آمن حالًا.** دي اللي هتدخلي بيها صفحة الطلبات. لو ضاعت منك، افتحي Apps Script تاني واختاري **Project Settings ← Script Properties** وهتلاقيها قدام `ADMIN_TOKEN`.

---

## الجزء الثاني: نشر الكود كخدمة (٤ دقايق)

**٨.** من فوق على اليمين اضغطي **Deploy ← New deployment**.

**٩.** اضغطي أيقونة الترس ⚙ جنب "Select type" واختاري **Web app**.

**١٠.** اضبطي الخانتين دول بالظبط:

| الخانة | القيمة |
|---|---|
| Execute as | **Me** (حسابك) |
| Who has access | **Anyone** |

> ⚠️ **"Anyone" مهمة جدًا** — من غيرها الموقع مش هيقدر يبعت الطلبات. ومعناها إن الرابط مفتوح لاستقبال الطلبات فقط؛ **قراءة** الطلبات محتاجة كلمة السر.

**١١.** اضغطي **Deploy**، وبعدين انسخي الرابط اللي تحت **Web app URL**. هيكون شكله كده:

```
https://script.google.com/macros/s/AKfycby..../exec
```

---

## الجزء الثالث: ربط الموقع بالشيت (٣ دقايق)

**١٢.** افتحي ملف `js/config.js` من مجلد المشروع، ودوّري على السطر ده:

```js
  backend: {
    url: '', // PLACEHOLDER
  },
```

وحطي الرابط جواه:

```js
  backend: {
    url: 'https://script.google.com/macros/s/AKfycby..../exec',
  },
```

**١٣.** في نفس الملف، املي أرقام المحافظ اللي هتستقبلي عليها التحويلات:

```js
      accounts: [
        { label: 'فودافون كاش', labelEn: 'Vodafone Cash', value: '01012345678' },
        { label: 'إنستاباي',    labelEn: 'InstaPay',      value: 'bouquet@instapay' },
      ],
```

> أي سطر تسيبي `value` بتاعه فاضي هيختفي تلقائيًا من الموقع. ولو سيبتي الاتنين فاضيين، خيار التحويل كله هيختفي ويفضل الدفع عند الاستلام بس.

**١٤.** ولو عندك صفحة فيسبوك، حطي اسمها عشان زرار الماسنجر يظهر:

```js
  messenger: 'bouquet.parfums',
```

**١٥.** ارفعي التعديل:

```bash
git add -A && git commit -m "ربط سجل الطلبات" && git push
```

## الجزء الرابع: التجربة

**١٦.** افتحي الموقع، اعملي طلب تجريبي، وأكّديه.

لازم يحصل ٤ حاجات:
- الطلب يظهر في **جوجل شيت**
- **إيميل** يوصلك بتفاصيل الطلب
- **واتساب** يفتح بالرسالة
- الطلب يظهر في `https://salma-alwardany.github.io/bouquet-parfums/admin.html` بعد ما تدخلي كلمة السر

لو حصلوا كلهم ✅ خلصنا.

## إضافة إشعارات تليجرام (اختياري — ٥ دقايق)

التليجرام أسرع وأضمن من الإيميل لأن الإشعار بيوصل فورًا على موبايلك.

**١.** افتحي تليجرام ودوّري على **@BotFather**.
**٢.** ابعتيله `/newbot`، واختاري اسم للبوت وبعده username لازم ينتهي بـ `bot` (مثال: `bouquet_orders_bot`).
**٣.** هيديكي **توكن** شكله `7812345678:AAH...`. انسخيه.
**٤.** ارجعي لـ Apps Script، دوّري على دالة `setTelegram` وحطي التوكن:

```js
  var botToken = '7812345678:AAH...';
  var chatId = '';
```

احفظي وشغّلي الدالة (Run).

**٥.** في تليجرام، افتحي البوت اللي عملتيه واضغطي **Start** أو ابعتيله أي رسالة.
**٦.** في Apps Script شغّلي دالة **findTelegramChatId**، وافتحي **Execution log** تحت — هتلاقي سطر مكتوب فيه `رقم المحادثة: 123456789`. انسخي الرقم.
**٧.** ارجعي لـ `setTelegram`، حطي الرقم في `chatId`، احفظي، وشغّلي الدالة تاني.
**٨.** شغّلي دالة **testNotification** — المفروض توصلك رسالة على تليجرام وإيميل.

---

## تغيير إيميل الإشعارات

افتراضيًا الإشعارات بتروح على نفس حساب جوجل اللي عملتي بيه الشيت. لتغييره: افتحي دالة `setNotifyEmail` في Apps Script، غيّري الإيميل، واحفظي وشغّليها.

---

## حاجات مهمة تعرفيها

**لو عدّلتي الكود في Apps Script بعد كده** لازم تعملي **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy** عشان التعديل يشتغل. (الرابط مش بيتغير.)

**كلمة السر** هي الحماية الوحيدة للوحة التحكم. أي حد يعرف الرابط + كلمة السر يقدر يشوف طلباتك وبيانات عملائك. متبعتيهاش في جروبات، وغيّريها لو شكّيتي إنها اتسرّبت (من Project Settings ← Script Properties ← عدّلي `ADMIN_TOKEN`).

**حدود جوجل المجانية:** حوالي ١٠٠ إيميل في اليوم. كفاية جدًا لمتجر صغير، ولو الطلبات زادت عن كده التليجرام والشيت هيفضلوا شغالين عادي.

**لو الإنترنت قطع** على العميلة وقت الطلب، الطلب بيتحفظ على جهازها وبيتبعت تلقائيًا أول ما تفتح الموقع تاني — فمفيش طلب بيضيع.

**الشيت هو المرجع.** لو غيّرتي حالة طلب من الشيت مباشرة، لوحة التحكم هتشوف التغيير. بس متمسحيش عمود **«بيانات (لا تعدّليها)»** المخفي لأن فيه تفاصيل الطلب كاملة.
