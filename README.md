# بوكيه — Bouquet Parfums | دليل الموقع

موقع دار عطور بوكيه: عربي (من اليمين لليسار) مع زر للتبديل إلى الإنجليزية.

**🌐 الموقع منشور على:** https://salma-alwardany.github.io/bouquet-parfums/
**📦 الكود على:** https://github.com/salma-alwardany/bouquet-parfums

## فتح الموقع
افتحي `index.html` في المتصفح، أو شغّلي خادمًا محليًا من داخل المجلد:
```
python -m http.server 5733
```
ثم افتحي http://localhost:5733

## الصفحات
| الملف | المحتوى |
|---|---|
| `index.html` | الرئيسية: الواجهة السينمائية، المقدمة، مشهد «من الزهرة إلى العطر»، المجموعة، اكتشفي عطرك، رحلة العطر، العطر المميز، قصتنا |
| `product.html?p=rose-de-nuit` | صفحة العطر (صور، أحجام، كمية، نوتات، «قد يعجبك أيضًا») |
| `checkout.html` | إتمام الطلب، ويُرسل الطلب إلى واتساب المتجر |
| `account.html` | طلباتي، المفضلة، بياناتي (محفوظة على جهاز العميلة) |
| `policies.html` | خدمة العملاء، الشحن والإرجاع، الخصوصية، الشروط |
| `admin.html` | **لوحة التحكم** — كل الطلبات، تغيير حالتها، وتأكيدها على واتساب (ليكِ أنتِ فقط) |

## ما تحتاجين تعديله (وأين)
- **الإعدادات العامة:** `js/config.js`: رقم واتساب، إظهار الأسعار أو إخفاؤها، روابط إنستغرام وفيسبوك وتيك توك، العطور المعروضة في كل قسم.
- **العطور:** `js/products.js`. **كل العطور الحالية تجريبية** (الأسماء والأوصاف والنوتات والأحجام والأسعار). استبدليها ببياناتك الحقيقية، واحذفي السطر `placeholder: true` من كل عطر بعد مراجعته.
- **النصوص والترجمة:** `js/i18n.js` (كل جملة لها نسخة عربية وإنجليزية).
- **نصوص السياسات:** في `js/i18n.js`، المفاتيح التي تبدأ بـ `pol.`.

زر **«محتوى تجريبي»** أسفل الشاشة يضع إطارًا منقّطًا حول كل محتوى مؤقت يجب استبداله. أخفيه قبل الإطلاق: `previewBadge: false` في `js/config.js`.

## الصور والفيديو
كل الصور مأخوذة من فيديوهات بوكيه الموجودة في مجلد `design`.
- صور العطور: `assets/img/اسم-العطر-1-864.webp` و `…-560.webp` (نسبة 4:5).
- فيديو الواجهة: `assets/video/hero.mp4`
- الشعار والزهرة: `assets/brand/` (الشعار كما هو دون أي تعديل، والزهرة مقتطعة منه).

لإضافة صورة لعطر جديد: احفظيها بحجمين (864×1080 و560×700) بصيغة webp، ثم اكتبي اسمها داخل `images` في `js/products.js`.

## الطلبات ولوحة التحكم

كل طلب يُسجَّل في **٣ أماكن** حتى لا يضيع أبدًا:
1. **جوجل شيت** عندك ← لوحة التحكم تقرأ منه
2. **إيميل + تليجرام** يصلك فورًا بتفاصيل الطلب
3. **واتساب** — رسالة جاهزة ترسلها العميلة إلى رقمك

وكمان يُحفظ على جهاز العميلة نفسها لتشوفه في صفحة «حسابي».

> ⚙️ **عشان ده يشتغل لازم تعملي الإعداد مرة واحدة** — الخطوات بالصور والتفصيل في:
> **[`apps-script/دليل-الإعداد.md`](apps-script/دليل-الإعداد.md)** (١٥ دقيقة، نسخ ولصق بس)
>
> قبل الإعداد الموقع شغال عادي، لكن الطلبات بتتبعت واتساب فقط ولوحة التحكم بتبقى فاضية.

### لوحة التحكم
`admin.html` — تفتحيها بكلمة السر اللي هتطلع لك وقت الإعداد. فيها:
- كل الطلبات بحالاتها (جديد / مؤكد / تم الشحن / تم التسليم / ملغي) وبحث وفلترة
- إحصائيات اليوم والشهر
- تفاصيل كل طلب: العطور، العنوان، رقم التحويل، ملاحظات العميلة
- **زرار واحد يفتح واتساب العميلة برسالة تأكيد جاهزة** تقدري تعدّليها قبل الإرسال
- ملاحظة داخلية لكل طلب (مش بتظهر للعميلة)
- تصدير كل الطلبات لملف Excel

الصفحة مش بتظهر في جوجل (`noindex`)، لكن **كلمة السر هي الحماية الوحيدة** — متشاركيهاش مع حد.

### طرق الدفع
- **الدفع عند الاستلام** — شغّال افتراضيًا.
- **تحويل على محفظة أو إنستاباي** — تحطي أرقامك في `js/config.js`، والعميلة تشوفها وتكتب رقم عملية التحويل (اختياري، لأن الشحن بيتحدد معاكِ على واتساب الأول). أي رقم تسيبيه فاضي بيختفي لوحده.

> **الدفع بالفيزا** يحتاج حساب تاجر من بوابة دفع (Paymob أو Fawry)، وده يتطلب **سجل تجاري وبطاقة ضريبية**. لما تتوفر، الربط إضافة بسيطة.

## تحديث الموقع بعد أي تعديل
أي تعديل تعمليه على الملفات لازم يترفع عشان يظهر على الإنترنت:
```bash
git add -A
git commit -m "وصف التعديل"
git push
```
الموقع بيتحدّث لوحده خلال دقيقة تقريبًا بعد الرفع.

> مجلد `design` (فيديوهات البراند وملف الفوتوشوب) **مستثنى من الرفع** لأنه ٢٨ ميجا وغير لازم للموقع — الصور المستخرجة منه كلها في `assets`. يعني الفيديوهات الأصلية موجودة على جهازك بس، فاحتفظي بنسخة منها في مكان آمن.

## قبل الإطلاق
1. استبدال بيانات العطور التجريبية وصورها.
2. إضافة روابط التواصل الاجتماعي ونصوص الشحن والخصوصية والشروط.
3. `previewBadge: false`.
4. (تم) الموقع منشور على GitHub Pages — أي تعديل بيظهر بعد `git push`.
5. اختياري: ربط دومين خاص (مثل bouquetparfums.com) بدل رابط github.io.
